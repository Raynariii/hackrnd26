# Корпус тестовых монолитов (роль 4)

Каждый пример — отдельная папка:

```
corpus/<NN-название>/
  Main.java          # или несколько .java; один класс с main
  inputs/*.txt       # stdin-входы для запуска и дифф-тестов
  NOTES.md           # какие конструкции scope покрыты и какие дефекты заложены
```

Требования к набору (PLAN.md §4, роль 4):
- 5–8 монолитов по ~1000 строк;
- вместе покрывают разделы 1–4 обязательного scope (язык и java.lang, консольный ввод-вывод, коллекции java.util, исключения)
  + бонус: record, enum, дженерики, лямбды, Stream API;
- в каждом — заложенные дефекты для анализатора (O(n²), contains в цикле, конкатенация строк в цикле, дублирование, длинные методы);
- каждый пример проверен руками: компилируется, детерминированно выводит одно и то же на одних входах.

`00-hello` — минимальный пример для smoke-тестов.
