# Корпус тестовых монолитов (роль 4)

Каждый пример — отдельная папка; любая новая папка автоматически проверяется тестами ядра (`CorpusRoundTripTest`:
разбор, печать байт-в-байт, графы), анализатора (`CorpusAnalysisTest`) и песочницы (`CorpusSmokeTest`: компиляция,
запуск всех входов, детерминированный вывод).

```
corpus/<NN-название>/
  Main.java          # один файл, один класс с main
  inputs/*.txt       # stdin-входы: дифф-тесты /verify берут их автоматически, если загружен этот пример
  inputs/bench-<n>.txt   # входы растущего размера для бенчмарка /verify (benchmark=true)
  NOTES.md           # какие конструкции scope покрыты и какие дефекты заложены
```

| Пример | Строк | Акцент scope | Ключевые дефекты |
|---|---|---|---|
| `00-hello` | 25 | smoke | `contains` в цикле |
| `01-shop-orders` | ~660 | 1, 2, 3, 4: классы, наследование, свои исключения | O(n²) дубли, `contains`, конкатенация, `LinkedList.get`, длинный метод, пустой `catch`, дублирование |
| `02-library` | ~630 | 3, 4: коллекции, `Iterator`, `Optional`, `List.of`, иерархия исключений | O(n²), конкатенация, `LinkedList.get`, дублирование |
| `03-bank` | ~550 | 1, 2: примитивы, массивы, `Math`, обёртки, `Formatter`, `StandardCharsets`, код выхода | конкатенация, O(n²), вложенность, магические числа |
| `04-text-stats` | ~500 | 1, 2: `String`, `Character`, кириллица, метки циклов | O(n²) анаграммы, конкатенация, вложенность |
| `05-course-grades` | ~440 | бонус: record, enum, sealed, дженерики, лямбды, Stream, Collectors | `contains` в цикле, O(n²), пересчёт в компараторе |
| `06-demo-warehouse` | ~200 | **демо**: три исправимых O(n²) → O(n), ускорение ×6,5 на n = 20000 | `contains`, конкатенация, `LinkedList.get` |

Матрица «конструкция scope → пример → граф/генерация/тест» — в [`docs/scope.md`](../docs/scope.md).

## Инструменты

```bash
python3 corpus/gen_bench.py   # пересоздать bench-<n>.txt (детерминированно, seed = n)
corpus/check.sh [пример...]   # вручную: компиляция, запуск каждого входа дважды, сравнение вывода, время (JDK 21)
```

Требования к примеру: компилируется `javac` 21 без предупреждений-ошибок; на одном входе всегда одинаковый stdout,
stderr и код выхода (никаких `java.time`, `Random` без seed, потоков, файлов, сети); каждый вход (кроме bench)
выполняется быстрее 1 с, bench — быстрее 10 с (таймаут verify).
